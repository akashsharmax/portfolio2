# Akash Sharma — Portfolio v2

Stunning, fully dynamic portfolio built with React 18. No build step required.

## ✨ Features

- **Live particle network** — interactive, mouse-reactive canvas background with grid
- **Custom smooth cursor** — dot + ring that follows your mouse with lag effect
- **Glitch hero animation** — name glitches with RGB split on loop
- **Typewriter effect** — cycles through 5 roles with realistic typing
- **Scroll reveal animations** — elements fade up as you scroll
- **3D card tilt** — project cards tilt in 3D on hover
- **Accordion experience** — click to expand internship details
- **Resume download** — generates and downloads a formatted HTML resume
- **Fully responsive** — mobile-friendly layout

## 📂 Files

portfolio2/

## 🚀 Run Locally

```bash
# Option 1: Python server (recommended)
cd portfolio2
python -m http.server 3000
# Open http://localhost:3000

# Option 2: VS Code Live Server
# Right-click index.html → Open with Live Server

# Option 3: Double-click index.html
```

## 🌐 Deploy to GitHub Pages

```bash
git init
git add .
git commit -m "🚀 Launch portfolio"
git branch -M main
git remote add origin https://github.com/akashsharmax/portfolio.git
git push -u origin main
```
Then: **Repo Settings → Pages → Branch: main → / (root) → Save**

Live at: `https://akashsharmax.github.io/portfolio`

## 🔧 Customize

- **Links** → Update GitHub/LinkedIn/Instagram URLs in `app.jsx` → `CONTACTS` array
- **Projects** → Edit `PROJECTS` array in `app.jsx`
- **Colors** → Edit CSS variables in `index.html` `:root` block
